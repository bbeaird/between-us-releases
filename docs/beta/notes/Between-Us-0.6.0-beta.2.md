# Between Us 0.6.0-beta.2 — updater verification release

Build 4 follows the corrected beta.1.1/build 3 manual bridge and retains its Sparkle framework startup repair. This release provides the next signed build for the first real in-app upgrade verification; it introduces no new Messages-analysis features.

Requires Apple silicon and macOS 14 or newer. On beta.1.1, use Between Us → Check for Updates. Older installations and broken beta.1 require a manual install from the DMG.

Messages and Contacts remain local. Cloud AI requires explicit provider setup and consent. This update does not download a model or enable cloud AI or encrypted backups. Automatic update downloads remain off by default.
