Between Us Privacy Policy

Effective October 23, 2026 · Developer: Brantley Beaird

What stays on this Mac

Between Us reads your Messages database read-only and, if you allow it, Contacts to show names. Analysis and Local Gemma answers run on this Mac. Cloud API keys are stored in macOS Keychain. Nothing from Messages or Contacts leaves this Mac unless you ask a cloud AI question.

Usage analytics

On by default: the first-run step shows “Shares anonymous usage stats.” with its toggle, and nothing is sent before it appears. Events go to Segment, which passes them to Google Analytics.

Events: app_opened, screen_view, messages_connection_requested, messages_connection_completed, messages_connection_failed, analysis_requested, analysis_completed, analysis_failed, ai_question_requested, ai_question_completed, ai_question_failed, local_model_download_started, local_model_download_completed, local_model_download_failed, local_model_load_result, conversation_table_interacted, comparison_window_changed, backup_result, restore_result, retry_requested, empty_state_viewed.

Properties, each limited to fixed values: launch_source, screen_name, previous_screen_id, stage, preset_range, trigger, engine, latency_bucket, error_code, model_id, result, action, column_id, view_id, operation, attempt_bucket, previous_error_code, feature_id, reason. Every event also carries app, platform, app_version, build, environment, data_mode, surface, schema_version, engagement_time_msec (always 1), timestamp, random messageId and session_id, operation_id linking requests to results, and anonymousId: a random identifier created each time the app opens and never saved. No message text, names, questions, answers or search terms are included.

Segment sees the IP address each request comes from; the event’s own IP field is 0.0.0.0.

Turn it off on the first-run step, in Help (?), or in Between Us › Usage Analytics…. This stops future sends but does not delete events already sent. See Segment (Twilio) privacy and Google privacy.

Other connections

  • Updates: when you choose Check for Updates… or turn on automatic checks, the app asks GitHub for updates, sending its version but no system profile.
  • Local AI: only when you download it, the app fetches the 18.4 GB Gemma model from Hugging Face, sending its version and any Hugging Face access token saved on this Mac.
  • Cloud AI (OpenAI, Anthropic, xAI): off until you allow cloud AI, add your API key and choose that provider. Each question about one person then sends that provider your question, the person’s name as shown (from Contacts if allowed), the date range, that conversation’s statistics, every readable message in the range with its ID, date, time and sender, up to six earlier questions or answers from this session, and your key. Questions across conversations stay on this Mac.

Each service sees your IP address; its own policy applies.
